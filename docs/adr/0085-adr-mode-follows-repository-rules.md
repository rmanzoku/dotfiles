# Context

ADR 0082 の Decision 5 で、共通ルールに「ADR やドキュメントは過去の判断の記録であり、現時点でも最適であることを示さない」と書いた。

2026-10-31、oasyswallet/ow-management は ADR を今有効な決定だけに保つ運用に変えた。決定が変わったら ADR を書き直し、無効になった ADR は削除する（同リポジトリの `governance/agent-shared-rules.md` §9。PR oasyswallet/ow-management#89 で導入）。共通ルールの「過去の判断の記録」という書き方は、この運用とぶつかる。利用者は共通ルールも合わせて直すことに同意した。

# Decision

共通ルールの「Markdown / ADR 運用」節を次のように変える。

1. ADR を過去の判断の記録として積み上げるか、今有効な決定だけに保つかは、作業リポジトリの正規指示に従う。指定がなければ、過去の判断の記録として扱う。
2. 今有効な決定だけに保つ運用では、決定が変わったら該当 ADR を書き直し、無効になった ADR は削除する。
3. ADR やドキュメントの記述が現在の目的・利用者の指示・観測事実と食い違う場合は、記録に合わせて判断を曲げず、食い違いを示して見直しを提案する。この趣旨は ADR 0082 から変えない。
4. 作業日時と Agent のモデル名は Front Matter に記載する、と明記する。

既定を「過去の判断の記録」にしたのは、ほかのリポジトリ（このリポジトリを含む）が今の積み上げ運用のまま動くようにするため。

# Consequences

- ADR 0082 の Decision 5 は、この ADR で置き換える。ADR 0082 本文は過去の判断の記録として残す。
- 共通ルールの bullet は 1 つ増える。既存 bullet を割って、ADR の性格と食い違い時の扱いを分けたため。
- このリポジトリの ADR は、これまでどおり積み上げで運用する。
